# FLUXUS: Feed System SImulator

Fluxus is a physics based fluid solver, capable of simulating flowpaths from COPV to engine for pressure-fed systems. Additionally PID control can be tuned for valves.


## Instructions:
1. In the control_system_tester file you create the flow paths in the feed system to be simulated. This can be made up of instances of the COPV (pressure vessels), propellant tanks and valve classes.

2. Run tkinter test file. This will open as shown.
   a. Upload the desired runplan as a csv file.
<img width="809" alt="image" src="https://github.com/user-attachments/assets/19f38a1f-c96e-4ce4-8170-de736b0c5bf8">

   b. Input the starting parameter and valve PID variables click run button

   c. Graphs output the simulated feed system. PID variables can be tuned and rerun to achieve better control

Enjoy!
